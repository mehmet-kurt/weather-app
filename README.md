# weather-app
This application allows searching weather conditions of cities all over the world.

It is made using streamlit and requests libraries on python.

### How it works?

A User basically enters the name of the city and hits the enter button. Then, app shows an emoji describing the weather, temperature, and weather condition.

### Requirements

-streamlit
-requests
